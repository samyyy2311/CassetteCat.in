# CassetteCat Website

The site at [cassettecat.caffeinelabs.in](https://cassettecat.caffeinelabs.in), deployed by Cloudflare Workers, which builds it from `main` on every push (see `wrangler.jsonc`).

The user guide for both apps is in `docs/`. Mintlify publishes it, and the Worker in `worker.js` serves it at [/docs](https://cassettecat.caffeinelabs.in/docs).
