CassetteCat plays the music on your computer, music on your own Subsonic or Jellyfin server, and internet radio. It runs on Windows 10 and 11, and Linux on x86_64 and ARM64. A macOS version is in development and isn't available yet.

## Install

<Tab title="Windows">

  <Card title="Microsoft Store" icon="store" href="https://apps.microsoft.com/detail/9NXNRR95X3K0">

Uninstalling with the installer asks before it deletes your settings and Listening Record.
</Note>

</Tab>
<Tab title="Linux">

Every package comes for x86_64 and ARM64 (aarch64). Download the one for your system from the [latest release](https://github.com/samyyy2311/CassetteCat-Desktop/releases/latest), then install it:

<CodeGroup>
```bash Debian, Ubuntu
sudo apt install ./CassetteCat-*.deb
```

```bash Fedora, RHEL
sudo dnf install ./CassetteCat-*.rpm
```

```bash openSUSE
sudo zypper install ./CassetteCat-*.rpm
```

```bash Flatpak
flatpak install --user CassetteCat-*.flatpak
```

```bash AppImage
chmod +x CassetteCat-*.AppImage
./CassetteCat-*.AppImage
```

```bash tar.gz
tar -xzf CassetteCat-*.tar.gz
./CassetteCat/bin/CassetteCat
```
</CodeGroup>

The AppImage and the `.tar.gz` run on most distributions without installing anything. The Flatpak works on any distribution with Flatpak.

</Tab>
</Tabs>

<Accordion title="Check your download" icon="shield-check">

Each release has a `SHA256SUMS.txt`. Download it next to your file, then:

<CodeGroup>
```bash Linux
sha256sum --check --ignore-missing SHA256SUMS.txt
```

```powershell Windows
Get-FileHash .\CassetteCat-*-windows-x64-setup.exe -Algorithm SHA256
```
</CodeGroup>

On Windows, compare the hash with your file's line in `SHA256SUMS.txt`.

</Accordion>

## First launch

A short setup runs the first time. You can change all of it later in **Settings**.

<Steps>
  <Step title="Welcome">
    A quick look at what CassetteCat does.
  </Step>
  <Step title="Choose your music">
    Add the folders that hold your music. CassetteCat builds your library from them and picks up new files as you add them. You can add more folders, or leave some out, in **Settings > Music Library** later.
  </Step>
  <Step title="Make it yours">
    Pick an accent colour and how the app looks.
  </Step>
</Steps>

Your library appears on **Home** once the first scan finishes. If songs are missing, see [Troubleshooting](/desktop/troubleshooting#library).

## Finding your way around

The sidebar on the left holds the main pages:

- **Home**: picks from your library that change with the time of day, a shuffle card for everything, and sections such as Heavy Rotation and Recently Played.
- **Library**: Songs, Artists, Albums, Genres, Folders and Playlists. See [Library and playlists](/desktop/library-and-playlists).
- **Jellyfin** and **Subsonic**: your own music servers. See [Streaming, radio and online services](/desktop/streaming-and-radio).
- **Radio**: internet radio stations.
- **Search**: songs, artists, albums and genres, with your recent searches.
- **Listening Record**: your listening history and stats.
- **Settings**: everything else.

**Ctrl+B** (**Cmd+B** on a Mac) hides or shows the sidebar.

The **player bar** at the bottom shows what's playing. Click the cover to open **Now Playing**. The buttons on the right open the phone remote, lyrics, the queue, the mini player and Now Playing.
